#########
Endpoints
#########

ESPN API serves a lot of endpoints. This package groups those endpoints into categories each of which can be called via dedicated ``EspnApiClient`` methods.

ESPN does not have an own documentation of all available endpoints. As this could be intended, **there is no guarantee for all other endpoints to work properly and as expected in the future**.
