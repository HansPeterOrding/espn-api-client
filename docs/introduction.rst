############
Introduction
############

This library was created to enable coders in the football bubble to work easily with the data provided by ESPN. Therefore, it introduces an api client to call all existing endpoints of the ESPN api and transform the resulting JSON data into :doc:`data-transfer-objects`. The JSON data is mapped to object attributes so that you can use getters and setters to work with the data.

If you have not heard of ESPN API so far, it is a good idea to use Google and find out more. Unfortunately, there is no official documentation.
