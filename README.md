ESPN API client
===============

<!-- badges: start -->
<!-- ![GitHub release (latest by date)](https://img.shields.io/github/v/release/HansPeterOrding/espn-api-client?label=development%20version) -->
<!-- badges: end -->

API Client to consume the inofficial ESPN API with a PSR-18 compatible HTTP Client and transform results into DTO.

Package contains:
* Data transfer objects (DTO)
* API client factory
* API client with endpoints
